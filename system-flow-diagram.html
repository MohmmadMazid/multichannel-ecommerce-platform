Key End-to-End Flows
1. Publish Flow
Forms → API Client → Auth → Sync Engine → BullMQ / Fallback → Shopify / eBay
2. Oversell Protection
Shopify Sale → HMAC Webhook → Webhook Verifier → Mongo Stock → Fan-Out sync to eBay
3. Worker & Fallback
BullMQ Queue → Worker Daemon (Concurrency: 5) • Auto Direct Fallback on Redis offline
